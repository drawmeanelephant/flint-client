# Flatlophone documentation theme

Adapted from Boris's `themes/boris` at
`08969742f85238443ce5cd1cd53ceab1b1f3f85a`.
The documentation shell, CSS primitives, and first-party inline search retain
their MIT notice in `assets/boris-LICENSE.txt` (also copied into the published
site). The brand layer is local: warm paper, ink, red accents, and a stamped
wordmark. No remote assets, fonts, JS packages, or framework are needed.

The search index URL is derived from the page-relative stylesheet, preserving
nested routes and the GitHub Pages project prefix. Navigation remains available
without JavaScript; on small screens the enhanced menu starts collapsed.
The local search adaptation applies heading bonuses only to matching sections,
so unmatched queries return no results. Code wraps rather than requiring a
mouse to scroll narrow examples.
Wide reference tables receive a keyboard focus stop for horizontal scrolling.
Keep skip links, keyboard focus, narrow stacking, reduced-motion and print
behavior when changing the theme.
